Column definitions

What each column means

ColumnMeaning
area_code, area_namePSGC-based area code and name (regions use R_<name>, Quezon City QC)
forecast_made_week_endingLast week of data the forecast used (weeks end on Sunday)
weeks_ahead, target_week_endingHow far ahead, and the week being forecast
cases_low, cases_middle, cases_highLikely range of reported cases that week (10th, 50th, 90th percentile, calibrated to cover 80%)
cases_middle_per_100kMiddle forecast per 100,000 people
usual_level, epidemic_thresholdAverage for that week in earlier years, and that average + 2 standard deviations
alert_levelnormal, above usual, watch (high forecast above the epidemic threshold), outbreak warning (middle forecast above it)
populationPopulation used (OCHA COD-PS, 2022)

Regional and Quezon City forecasts build on the UPRI-NOAH Dengue–Rainfall Dataset (ODC-ODbL). Please credit EpiLag-PH and the original sources listed in the repository README. A machine-readable list of files is in index.json.
