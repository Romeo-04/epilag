Did it work?

Tested honestly. No peeking at the future.

Every test year was forecast only from earlier years, against two simple rules: "same week last year" and "same as this week".

Honest limits. The watch level also raises false alarms (42–63% of warnings, 87% in one year); the stricter warning level has fewer. Weather adds little beyond recent cases and season, so EpiLag-PH runs on data LGUs already have. Province data ends in January 2021, so the province view is a replay.
